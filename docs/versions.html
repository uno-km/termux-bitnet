Changelog history and immutable releases

v1.0.6 - Zero-Isolation Fast Build & Dual CLI Namespace Architecture

Latest Production Release 2026-08-26
  • pip-build-env CMake 소스 컴파일 병목 완전 제거: pyproject.toml의 build-system.requires에서 cmake 의존성을 제거하여 pip 빌드 격리 환경 내 수십 분 소요 C++ 컴파일 시도를 원천 차단하고 Termux 네이티브 cmake를 직접 바이패스 참조
  • npm EEXIST 글로벌 심볼릭 링크 충돌 해결: Node.js 패키지의 실행 파일명을 termux-bitnet-js 및 termux-bitnet-node로 분리 정의하여 Python termux-bitnet 바이너리와 충돌 없이 독립 공존
  • 원터치 인스톨러(install.sh) 최적화: 선행 setuptools/wheel 프로비저닝 및 pip install --no-build-isolation -e . 적용으로 2중 컴파일 비효율 제거 (빌드 시간 14s -> 3s 단축)
  • Samsung Galaxy S20 / ARM64 실기기 정밀 검증: granular-scoring 0-Point Baseline 기반 4대 핵심 기능 100/100 만점 획득 (하드웨어 SIMD 진단, 모델 레지스트리 파싱, Sub-5s 온디바이스 추론, 듀얼 엔진 API)
  • PyPI 및 npm 배포 아티팩트 동기화: termux-bitnet v1.0.6 sdist/wheel 및 npm tarball 패키징 완료

v1.0.5 - 1.58-bit GGUF Model Hub & Node.js Thin Gateway

Stable Release 2026-08-25
  • 4대 검증 1.58-bit GGUF 모델 레지스트리 (bitnet-2b, bitnet-large, bitnet-3b, bitnet-3b-q4) 인덱싱 및 HTTP Range 분할 다운로더 구현
  • Node.js Thin Gateway FFI 바인딩 및 비동기 토큰 스트리밍 API (generateStream) 구축
  • ARMv8.2-A DotProd (vdotq_s32) 및 NEON SIMD 어셈블리 가속 하드웨어 진단 기능 추가

v1.0.1 - Bionic libc Native C-ABI Stabilization

Maintenance Release 2026-08-22
  • Android Bionic libc 환경 내 메모리 매핑 및 ctypes 기반 C-ABI 인터페이스 안정화
  • OpenMP 멀티스레드 스케줄링 및 14대 하이퍼파라미터 매트릭스(BitNetConfig) 연동
