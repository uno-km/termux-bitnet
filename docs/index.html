Termux-BitNet

ARM64 NEON DotProd SIMD Accelerated 1.58-bit On-Device LLM Inference Engine

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-bitnet
# or: npm install termux-bitnet

The Engineering Challenge

Standard FP16/INT4 LLM inference on mobile CPU architectures encounters extreme memory bandwidth bottlenecks, thermal throttling, and severe battery drain exceeding 15W.

The Architectural Breakthrough

Executes 1.58-bit ternary quantized weights {-1, 0, +1} directly via hand-vectorized ARM64 NEON assembly kernels, reducing matrix multiplications to simple additions and subtractions with under 350MB RAM footprint.

Key Capabilities & Built-in Hardening

1.58-Bit Ternary DotProd Acceleration

Replaces multiplication with pure integer additions using ARM64 dot-product vector SIMD instructions.

Zero-PRoot Native Bionic Execution

Direct execution on Android Bionic libc without Linux PRoot containers or root privileges.

Dual-Engine Python & Node.js Gateways

Ultra-low overhead thin FFI bindings for both Python 3.8+ and Node.js 18+ runtimes.

Energy-Efficient Edge Deployment

Consumes under 2.5W during continuous token generation, preventing thermal throttling.

Canonical Usage Example

import termux_bitnet as bitnet

# 1. Load model with zero-copy mmap
model = bitnet.load_model("bitnet_b1_58-large.gguf")

# 2. Stream ultra-fast on-device inference
for token in model.generate("Explain quantum computing in one sentence:"):
    print(token, end="", flush=True)

import { BitNetEngine } from "termux-bitnet";

const engine = new BitNetEngine();
await engine.load("bitnet_b1_58-large.gguf");

const stream = engine.generateStream("Explain quantum computing in one sentence:");
for await (const chunk of stream) {
  process.stdout.write(chunk);
}
