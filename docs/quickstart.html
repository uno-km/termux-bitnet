Quickstart & Execution Recipes

Standard usage patterns and rapid prototyping code

Recipe 1: Model Hub Download & CLI Inference

Query verified 1.58-bit GGUF models, download with HTTP Range resume support, and execute instant inference:

# 1. List official verified models
termux-bitnet models

# 2. Download Microsoft BitNet 2B-4T (1.13 GB)
termux-bitnet download bitnet-2b

# 3. Run prompt inference with 4 CPU threads
termux-bitnet run -m ~/.cache/termux-bitnet/models/bitnet-2b-ggml-model-i2_s.gguf \
  -p "Explain quantum computing in one sentence." \
  -t 4 -c 2048 -n 64 --temp 0.7 --top-p 0.95

Recipe 2: Python SDK Token Streaming

Stream generated tokens asynchronously with context manager memory cleanup:

from termux_bitnet import BitNetEngine, BitNetConfig

config = BitNetConfig(
    model_path="models/bitnet-2b.gguf",
    n_threads=4,
    temperature=0.7,
    top_p=0.95,
    top_k=40,
    repeat_penalty=1.15
)

with BitNetEngine(config) as engine:
    print("[Prompt]: Explain quantum computing in one sentence.")
    print("[Response]: ", end="", flush=True)
    for token in engine.generate_stream("Explain quantum computing in one sentence:"):
        print(token, end="", flush=True)
    print()

Recipe 3: Node.js / TypeScript Gateway Streaming

const { createEngine } = require('termux-bitnet');

async function main() {
  const engine = createEngine({
    modelPath: 'models/bitnet-2b.gguf',
    threads: 4,
    temperature: 0.7,
    topP: 0.95
  });

  console.log('[Prompt]: Explain quantum computing in one sentence');
  console.log('[Response]: ');

  await engine.generateStream(
    'Explain quantum computing in one sentence',
    64,
    (token) => {
      process.stdout.write(token);
    }
  );
  console.log('\n');
}

main();

Recipe 4: OpenAI-Compatible Local HTTP API Server

# Start local API server on port 8080
termux-bitnet serve --port 8080 --model ~/.cache/termux-bitnet/models/bitnet-2b-ggml-model-i2_s.gguf

# Query via standard OpenAI client or curl
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "bitnet-2b",
    "messages": [{"role": "user", "content": "Hello BitNet!"}]
  }'
